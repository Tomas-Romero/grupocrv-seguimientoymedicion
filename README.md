# Seguimiento y Medición — Ingeniería y Calidad de Software

Proyecto académico desarrollado para la cátedra de **Ingeniería y Calidad de Software**. La aplicación está enfocada en el diseño e implementación de un sistema de seguimiento y medición de métricas para la gestión, control y evaluación de la calidad en procesos de desarrollo de software.

## 🛠️ Tecnologías y Herramientas

- **Metodología:** Scrum / Desarrollo Ágil
- **Gestión del Proyecto:** GitHub Projects & Issues
- **Control de Versiones:** Git & GitHub
